# Noor - القرآن الكريم

تطبيق أندرويد لعرض القرآن الكريم والاستماع إلى التلاوات، مبني باستخدام HTML داخل WebView.

## المميزات

- عرض القرآن الكريم.
- تشغيل التلاوة.
- اختيار القارئ.
- تشغيل السورة كاملة أو آية بآية.
- حفظ البيانات محليًا.
- قسم الأحاديث.
- واجهة عربية ودعم RTL.

## البناء

يتم بناء التطبيق تلقائيًا بواسطة GitHub Actions.

## معلومات المشروع

- Package: `com.amine.noor`
- Minimum SDK: 23
- Target SDK: 35
- Java: 17
- Android Gradle Plugin: 8.7.3
