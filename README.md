# نور — Noor Quran Android App

هذا المشروع يحوّل نسخة `index.html` المرفوعة إلى تطبيق Android خفيف باستخدام WebView.

## ما يحتويه
- القرآن الكريم والتلاوة والبحث الموجودة في نسخة HTML.
- الأحاديث الموجودة في النسخة المرفوعة.
- التخزين المحلي للسور والمحتوى الذي يدعمه الموقع.
- فتح روابط المصادر الخارجية في المتصفح.
- GitHub Actions لبناء APK تلقائيًا.

## بناء APK على GitHub
1. ارفع المشروع إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل **Build Noor APK** يدويًا، أو ادفع Commit جديدًا.
4. بعد انتهاء البناء افتح الـworkflow ثم **Artifacts**.
5. نزّل `Noor-debug-apk` وستجد `app-debug.apk`.

> التطبيق يحتاج الإنترنت أول مرة لجلب نصوص القرآن والتلاوات من واجهة AlQuran Cloud كما يفعل ملف HTML الأصلي. السور التي يحفظها الموقع محليًا يمكن قراءتها لاحقًا من التخزين المحلي.

## معلومات البناء
- Android Gradle Plugin: 8.7.3
- Gradle: 8.9
- JDK: 17
- minSdk: 23
- targetSdk: 35
- applicationId: `com.amine.noor`
